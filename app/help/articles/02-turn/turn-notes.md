Write down what you're trying, or why, as you play. Each player has one note per turn, and it's saved with that turn's node in the Multiverse.

## Write a note

:::desktop
Type in the **Turn N notes** box at the bottom left of the board. It saves when you click away.
:::

:::phone
{gesture:long-press} (long press) an empty part of the board. A **Turn N notes** dialog opens with the note for the player to play. Press **Save**, or **Cancel** to leave it as it was. {key:Enter} adds a line; {key:Ctrl+Enter} saves.
:::

[Show me](show:turn-notes)

The note shows in the game log under the turn it belongs to, as **Turn N note · Player N**.

## Where the note goes

When the turn ends with auto-save on, the note goes into the new node, above the recap of the turn. **Save current unfinished turn** in the Multiverse starts its note from it too. To change a note later, edit it in the Multiverse panel. See [The Multiverse panel](help:multiverse-panel).

## Good to know

- The note belongs to the player to play and the turn number. The other player's turn starts with an empty box.
- Hotkeys don't fire while you type in the notes box.
- Saving an empty note clears it.
